# Deals data: rules for agents

- This repository holds the Organization's own salespeople, companies,
  contacts, deals, activities, price list, quotes and forecast. It is private to the Organization; never copy its records into
  another Organization or into the public Deals template.
- Write records through the Deals App or its tools: every write is a draft
  that a person reviews and publishes in the App. Publishing is a Publication:
  only on the user's instruction. A pull request to `v3` is the other way.
- Never contact a company or a person from here, and never send a quote or an
  invoice. That is the person's step.
- Never commit anything under `generated/` or `.repository-db/`.
- `schemas/` is generated by the Deals App (`bun run schema:export` in its
  `app/v3`). Change the Zod schema there and copy the result here in the same
  release; never edit a schema here by hand.
- A record changed by hand, past the App, gets a new `record.revision`
  (`crypto.randomUUID()`) and `record.updatedAt` (now, UTC with milliseconds),
  as every write of the App does; never keep the old ones or copy them from
  another record. `record.updatedBy` names the person the change is for, or is
  left out.
- A change of the data's shape comes with the App's release: its
  `bun run migrate` writes it, the person reviews and publishes it in the
  App. Never reshape records by hand.
- Run `bun scripts/validate.ts` and the App's `bun run validate:db` before you
  open a pull request.
