# Deals data

The salespeople, companies, contacts, deals, activities, price list, quotes
and forecast of one Organization's sales pipeline, read and written by its Deals App through
[repository-db](https://github.com/Lazurio/repository-db). This repository is
checked out on branch `v3` as the `db/` directory of the Deals Module.

| Path | Holds |
| --- | --- |
| `data/settings/settings.yaml` | the settings: the currency, the stages of the pipeline, the loss reasons, the deal types, the billing entities, what a new quote starts with, the days an invoice is due |
| `data/salespeople/<id>.yaml` | one salesperson (`S-0001`) |
| `data/companies/<id>.yaml` | one company (`C-0001`) |
| `data/contacts/<id>.yaml` | one contact person (`P-0001`) |
| `data/deals/<id>.yaml` | one deal (`D-2026-0001`), with its payment plan once won |
| `data/activities/<id>.yaml` | one call, meeting, e-mail, note or task of a deal (`A-2026-00001`) |
| `data/pricebook/<id>.yaml` | one item of the price list (`I-0001`) |
| `data/quotes/<id>.yaml` | one revision of a quote (`Q-2026-0001-r1`) |
| `data/forecastEntries/<id>.yaml` | one manual row of the forecast (`F-2026-0001`) |
| `data/forecastNotes/<month>.yaml` | a note on one month of the forecast (`2026-12`) |
| `schemas/<collection>.schema.json` | the schemas, generated by the Deals App; never edited here |
| `scripts/validate.ts` | the validator repository-db runs before every publish |

Every document is the envelope of repository-db (`schemaVersion`, `id`,
`record`). Amounts are whole haléře or cents (minor units) without VAT:
`139000` is 1 390,00 Kč. Data of Deals 0.1.x is migrated to 0.2.0 with the
App's `bun run migrate` (see the App's `docs/data.md`).

A change is published from the Deals App ("Koncept a publikování" / "Draft &
publish") or as a pull request to `v3`. Validate locally with
`bun scripts/validate.ts`.
