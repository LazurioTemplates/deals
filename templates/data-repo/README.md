# Deals data

The companies, contacts, deals and activities of one Organization's sales
pipeline, read and written by its Deals App through
[repository-db](https://github.com/Lazurio/repository-db). This repository is
checked out on branch `v3` as the `db/` directory of the Deals Module.

| Path | Holds |
| --- | --- |
| `data/settings/settings.yaml` | the settings: the currency, the stages of the pipeline, the loss reasons, the salespeople |
| `data/companies/<id>.yaml` | one company (`C-0001`) |
| `data/contacts/<id>.yaml` | one contact person (`P-0001`) |
| `data/deals/<id>.yaml` | one deal (`D-2026-0001`) |
| `data/activities/<id>.yaml` | one call, meeting, e-mail, note or task of a deal (`A-2026-00001`) |
| `schemas/<collection>.schema.json` | the schemas, generated by the Deals App; never edited here |
| `scripts/validate.ts` | the validator repository-db runs before every publish |

Every document is the envelope of repository-db (`schemaVersion`, `id`,
`record`). Amounts are whole haléře or cents (minor units): `139000` is
1 390,00 Kč.

A change is published from the Deals App ("Koncept a publikování" / "Draft &
publish") or as a pull request to `v3`. Validate locally with
`bun scripts/validate.ts`.
